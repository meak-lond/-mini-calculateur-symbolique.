# Mini Calculateur Symbolique

Un mini-calculateur symbolique en Python pur (tokenizer, parser, AST, évaluateur, simplification et dérivation symbolique).

## Fonctionnalités
- Analyse lexicale et syntaxique d'expressions mathématiques
- Évaluation numérique
- Simplification algébrique de base
- Dérivation symbolique
- REPL interactive
- Tests unitaires

## Utilisation
```bash
python3 calculateur_symbolique.py
